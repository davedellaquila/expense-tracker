# Expense Tracker

Personal + business income/expense tracker. All data lives in a Google Sheet.

- **index.html** — the tracker web app (single file). Open it in a browser, or use the
  GitHub Pages link. Paste your Apps Script Web app URL into Settings to connect it.
- **Code.gs** — Google Apps Script backend. In your Google Sheet: Extensions → Apps Script,
  paste this in, then Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone).

Keep your Web app URL private — anyone with it can read and write the sheet.
